# smelt-vim

Syntax highlighting and filetype detection for Smelt's `project.smelt` files, for Vim and Neovim.

## Installation

With [lazy.nvim](https://github.com/folke/lazy.nvim)

```lua
{
  "FloofyPlasma/smelt-vim",
  ft = "smelt",
}
```

Filetype detection applies to `project.smelt` and any `*.smelt` files.
